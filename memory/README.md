# Memory

Daily notes go in `YYYY-MM-DD.md` files here. Each file captures what the agent noticed or produced during a run on that date.

Format:

```markdown
# YYYY-MM-DD

## Run summary
- Request:
- Meals planned:
- Budget estimate:

## Notes
- anything unusual or worth remembering
```

The agent reads today and yesterday's files at the start of each session.
